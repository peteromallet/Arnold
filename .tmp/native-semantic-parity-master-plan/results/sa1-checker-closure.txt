### Finding 1 (CRITICAL): `check_workflow_file` bypasses all row-evidence checking

**`arnold/workflow/source_compiler.py:623–631`** — `check_workflow_file` defaults `evidence=None`. It delegates to `check_workflow_source` at line 632, which receives `evidence=None`.

**`arnold/workflow/source_compiler.py:687–691`** — The gate:

```python
row_evidence_diagnostics = (
    _row_evidence_diagnostics(parsed_source, evidence_records)
    if evidence is not None   # <-- False when check_workflow_file caller passes nothing
    else ()
)
```

When `evidence is None`, `_row_evidence_diagnostics` **never executes**. No AWF245 diagnostics are ever produced.

**`arnold/workflow/source_compiler.py:642–649`** — `check_workflow_source` defaults `evidence=()`, which DOES trigger the check (empty `()` is not `None`). But this function is only called from `check_workflow_file` — never directly by any CLI or external caller.

**All four CLI callers** (`arnold/cli/workflow.py:208`, `:437`, `:514`, `:677`) call `check_workflow_file(source_path)` with no `evidence` kwarg → evidence always `None` → AWF245 is **dead code in practice**.

**`arnold/workflow/source_compiler.py:687–713`** — Four diagnostic generators run independently:
