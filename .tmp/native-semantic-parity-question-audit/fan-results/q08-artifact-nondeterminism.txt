## Smallest Plan Amendment

Add a new section after line 39 and before §1:

```
### Canonicalization Layer Required Before Any Baseline Freeze

Before S1a can freeze a single golden baseline, the replay harness must
enumerate and neutralize every volatile field source.  The following
must be stripped or pinned to fixed values before content-hashing any
artifact that enters a baseline:

  Field                 Source                      Neutralization
  ─────                 ──────                      ──────────────
  generated_at          artifacts.py:68,99          Pin to epoch-zero or strip from payload
  invocation_id         phase_result.py:282,313     Pin to deterministic seed per scenario
  snapshot_id           state.py:995                Pin to deterministic seed
  session_id            state.py:1564,1695          Strip or pin to canned worker id
  absolute paths        artifacts.py:377            Replace with canonical resource paths
  model/provider names  state.py session entries    Strip or pin to canned identifiers
  timestamps in         status_snapshot.py:163,     Pin to epoch-zero
    snapshots           meta_repair.py:156

The canonicalization pass must run as a pipeline stage before any
sha256 is computed for baseline comparison, and the pass itself must
be hash-pinned as part of the harness fingerprint.
```

This is the minimal change needed to make the plan's hash-pinned baseline assumption defensible. Without it, S1a could freeze baselines that differ trivially due to wall-clock time or machine-local paths, rendering every subsequent parity comparison a false alarm.
