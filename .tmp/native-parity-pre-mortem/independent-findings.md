# Independent pre-audit findings

Formed after reading the representation report, corrective plan, initiative contracts, all S1–S7 briefs, and current authoring/lowering/runtime/handler/auto/resume/proof/scenario surfaces, but before reading the round-2 audit.

## Provisional verdict

`determinate with bounded sharpening`, close to `gameable in material ways` if the proof remains row-local. The plan decisively forbids the known 85→14 collapse and hidden carrier authority, but it does not yet force one ordered, causal, whole-workflow behavioral oracle or a safe first side-effect cutover.

## Candidate material gaps

1. **Row-local proof can be globally wrong.** The normative matrix is per product semantic (`docs/arnold/megaplan-native-parity-corrective-plan.md:394-419`), row evidence asks for a split-outcome trace per row (`:421-437`), and final proof emphasizes set equality (`:455-484`). None requires a stable, ordered, cross-row trace whose events bind source occurrence → RA decision → custody action → WBC attempt/effect → checkpoint/reentry → terminal outcome for the same run. A team can prove each row in isolated tests and run one unrelated/happy installed E2E. Current goldens demonstrate the danger: scenario IDs D1–D8 are executed by other pipeline builders in `tests/arnold_pipelines/megaplan/test_native_golden_traces.py:40-184`, while the manifest treats those files as Megaplan evidence (`docs/arnold/megaplan-native-representation-scenarios.yaml:18-227`). Amendment: S1 owns a machine-readable golden-trace contract and stable scenario IDs; S3–S6 incrementally execute it; S7 requires exact ordered trace/multiset and forbidden-observation assertions from checkout, wheel/sdist, and cloud.

2. **Set equality can erase invocation multiplicity and causal order.** The plan says semantic identity includes an invocation and generated mappings state cardinality/causality (`corrective-plan.md:113-138`), but its blocking language repeatedly asks for sets (`:455-464`) rather than occurrence multisets/ordered causal graphs. Loops, retry attempts, fallback, rework generations, and resume can reuse the same semantic path while being distinct logical occurrences. Amendment: define an invocation coordinate `(semantic_path, loop_generation, map_item_key, logical_retry_generation, reentry_generation)` and prove an ordered occurrence multiset/causal DAG, not only set equality. Retries retain logical child identity but create fresh RA/WBC attempts as declared; accepted effects retain idempotency identity.

3. **S5 lacks a side-effect cutover stop/go.** S3 has an explicit prep→plan seam before broad migration/deletion (`corrective-plan.md:287-311`; S3 brief `:9-20`), but S5 migrates the most dangerous surface—dynamic execution and external effects—under only an end-of-sprint gate (`corrective-plan.md:329-349`; S5 brief `:27-65`). Dual-running execute is unsafe and independent checkout/cloud passes do not prove a rolling mixed-host cutover. Amendment: add an S5 internal receipt before any legacy execute writer is disabled: one non-destructive real task and one idempotent effect run through canonical lowering, current M11 validation, relocated producer, crash-after-outcome reconciliation, installed artifact, and cross-host reclaim; canonical-source mutation changes trace, legacy mutation does not. Only then cut over remaining writers.

4. **Homogeneous installed parity does not reject mixed-version workers.** The plan binds program/policy/WBC digests to checkpoints/reentry (`corrective-plan.md:140-145`, `:474-477`) and compares checkout/wheel/cloud (`:483-484`), but it does not bind the executable program/topology + call-site-policy + installed-artifact digest to every authoritative dispatch/decision/effect envelope. A stale worker can accept a new-host action between checkpoints and still pass homogeneous environment tests. Current legacy cursors are only phase/payload (`arnold_pipelines/megaplan/runtime/resume.py:177-224`), illustrating the migration hazard. Amendment: every action envelope carries and validates source/topology, policy, WBC contract, and installed-artifact digests; mixed-version host tests must quarantine before phase-body/effect entry and repair only via pinned runtime or accepted new attempt/migration.

5. **Terminal/cancellation/publication arbitration is not a product contract.** S6 lists cancellation, halt, publication, and delivery (`corrective-plan.md:351-365`; S6 brief `:9-25`) and one-to-one decisions prevent duplicate consumption, but no text defines precedence or mutual exclusion across different accepted decisions. A cancel and publish can each be individually authorized and consumed. Amendment: add a closed terminal/action arbitration table and CAS invariant: the first accepted incompatible action determines the allowed successors; later conflicting decisions are rejected/quarantined; accepted effect outcomes remain history. Cover cancel-before-publish, publish-before-cancel-before-delivery, and delivery-before-late-cancel.

6. **Readability is subjective and future changes can recreate dual truth.** The end state requires the minimum readable workflow (`corrective-plan.md:66-87`) and S5 one reusable cycle, but final gate 14 is a human impression (`:518-519`). Current `workflow.pypeline` shows how a source-authoritative file can still be unusable: large literal route/interface tables (`arnold_pipelines/megaplan/workflows/workflow.pypeline:36-279`), duplicated execute/review/rework branches (`:388-754`), index-only execute paths (`:406-412`), and sequential tiebreaker calls (`:471-488`). Amendment: a small authoring readability contract—no route/policy/interface dictionaries in topology source, exactly one delivery-cycle call, one closed vocabulary declaration per decision family, generated identity/control-plane bindings, semantic complexity budget with reviewed exceptions, and six extension tests (new gate outcome, lens, retry, human decision, override, effect) that fail unless the authored topology is updated and prove no downstream carrier edit can add behavior.

7. **The composed history is not yet an operator acceptance surface.** The destination promises one durable composed history, and M11 supplies generic exact-version queries, but S6/S7 require projections and proof—not a Native-specific causal explanation/repair preflight. Current status derives `next_step` from projections/state (`arnold_pipelines/megaplan/cli/status_view.py:888-890`) and auto consumes it (`arnold_pipelines/megaplan/auto.py:3661-3669`); simply deleting that authority can leave operators with raw stores and no safe explanation. Amendment: require a read-only composed-run explanation derived from admitted queries that joins semantic occurrence, accepted RA decision/CAS, custody target/owner/epoch, WBC attempt/effect ambiguity, digests, current quarantine reason, and permitted repair target. Mutation tests prove it is observational only and disagrees loudly with forged projections.
