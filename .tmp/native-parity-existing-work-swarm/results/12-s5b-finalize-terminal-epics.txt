### 5. Recommended Adjustment to Sprint Plan

1. **Split S5 into S5a (review/rework) and S5b (finalize + terminal projection)** explicitly in the brief. The current `s5-review-rework-finalize.md` brief bundles them; extraction complexity differs substantially. S5b should depend on S5a + S4.

2. **Create the missing `test_review_finalize_native_flow.py`** as S5b's primary exit gate, covering at minimum:
   - `finalize → execute` projection (standard path)
   - `finalize → revise` fallback (baseline contract failure)
   - `finalize → done` (no-review terminal via bare/light robustness)
   - `finalize → awaiting_human_verify` (deferred-human terminal)
   - State/next_step assertions matching `_expected_final_projection_cases()`

3. **Remove or correct the evidence YAML references** to `test_path_resume_proofs.py` and `test_execute_terminal_projection_helpers_follow_source_policy_routes` — these are unverified claims that reference non-existent files. Either create them or remove them from the evidence ledger.

4. **Uplift `final_projection_routes` and `fallback_routes` from `FINALIZE_POLICY` metadata into named source constructs** in `workflow.pypeline` (or a declared policy attached to a named source construct), so the checker's `Mapping`-existence test is backed by actual source authority rather than component-metadata route tables.

5. **Require the dead-delete mutation gate** before S5b closeout: mutate `handlers/finalize.py` state-transition paths and prove scenarios are unchanged against frozen S1a baselines.
