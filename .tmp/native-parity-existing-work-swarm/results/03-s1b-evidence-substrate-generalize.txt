### 4. What Still Must Be Built

1. **Deterministic replay harness** — A Megaplan-specific harness that replays route/state traces using hash-pinned canned worker payloads (not live model output). Kernel replay cursor can be the substrate.

2. **Split-outcome completeness spec** — `docs/arnold/megaplan-native-required-split-outcomes.yaml` plus a validator that cross-checks the scenario inventory against required outcomes per sprint scope.

3. **Baseline freeze scripts** — `capture_megaplan_split_outcome_baselines.py` and `check_megaplan_baseline_freeze.py`. Existing test-suite baselines (`full_suite_backstop.py`) are the wrong abstraction — these must capture route/state/next-command/suspension assertions from legacy behavior.

4. **Headless control-injection API** — Programmatic actions for destructive approval denial, destructive approval approval, tiebreaker proceed/iterate/escalate. Must not require interactive CLI in CI.

5. **Installed-package strict source loading smoke** — Dedicated test (`test_installed_package_strict_source_loading.py`) that loads `workflow.pypeline` via `importlib.resources.files("arnold_pipelines.megaplan")` and feeds through `check_workflow_source(..., evidence=())`.

6. **Artifact canonicalizer** — Must normalize timestamps, UUIDs, absolute paths, invocation IDs, snapshot IDs, model/session IDs, and `generated_at`/`provenance` fields. Must embed canonicalizer version in every baseline record. Only required if artifact content hashes are used as parity proof (master plan: line 480).

---

### 5. Recommended Sprint Plan Adjustment

**Risk:** S1a (master plan: lines 435–459) already scopes the replay harness, canonicalizer, headless control injection, installed-package smoke, and baseline capture into one sprint alongside the checker hard bar, negative fixtures, carrier scan, and row registry. The evidence shows none of the S1b-adjacent scripts exist. If S1a truly intends to deliver these, it is overloaded.

**Recommendation:** Move the four "adjacent only" items (replay harness, baseline freeze, canonicalizer, headless injection) into S1b proper as a dedicated **S1b-0 Deterministic Evidence Substrate** sprint that lands before S1b-1 (runtime substrate proof) and S1b-2 (builder slice). This keeps S1a focused on checker authority and lets S1b-0 produce the harness and baselines that S2–S7 extraction sprints depend on for parity gates. The installed-package smoke can stay in S1a since strong infrastructure already exists.
