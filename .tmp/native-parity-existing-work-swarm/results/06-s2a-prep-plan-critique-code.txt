### 4. What Still Must Be Built

1. **Prep suspend/resume in canonical source** — `workflow.pypeline:390` is a bare `AUTHORING_PREP(...)` call with no suspend branch. The `front_half.pypeline` shape must be promoted into `workflow.pypeline` and the handler-based prep must be quarantined. The `AUTHORING_HALT` call must become a native halt/suspend construct.

2. **Plan artifact contract as source-visible policy** — `workflow.pypeline:391` calls `AUTHORING_PLAN(...)` with no declared artifact contract. `ARTIFACT_CONTRACT_POLICY` and `BLAST_RADIUS_POLICY` must be attached as declared policies on the native plan step, not component metadata.

3. **Critique evaluator retry as native construct** — The retry loop exists in `critique_runtime.py` (handler code). It must be extracted as a native subworkflow with typed outcomes or a declared retry policy attached to the critique fanout construct. The adaptive→static fallback declared in `components.py:944` must be either implemented (currently dead letter per `critique_runtime.py:392-396`) or removed.

4. **Selected-lens fanout/fallback as source-visible topology** — `workflow.pypeline:395-401` uses `items="megaplan.policy.critique_lenses"` — a runtime-resolved string reference. The lens fanout cardinality and selection/fallback behavior must be source-visible. The evaluator's per-lens complexity routing (in `critique_evaluator.py`) must either be source-attached policy or a native subworkflow.

5. **S2 exit-gate test missing** — `test_front_half_native_loop.py` is referenced in the master plan (`:628`) but **does not exist** in the tree. This test must be created.

6. **`front_half.pypeline` wiring** — Currently imported only by `route_dispatch.py:21` for routing step ID resolution. It is not a real execution path — it must become the canonical source or its constructs must be absorbed into `workflow.pypeline`.

### 5. Recommended Sprint Plan Adjustment

1. **S2 must produce `workflow.pypeline` with prep suspend/resume branching** as shown in `front_half.pypeline` — not defer to a separate file. The `front_half.pypeline` can serve as the extraction template but must become canonical or be deleted.

2. **Critique evaluator retry and selected-lens fanout** should be extracted together: the retry loop in `critique_runtime.py` AND the evaluator verdict logic in `critique_evaluator.py` form a single extraction unit. Extracting retry without lens selection/fanout visibility reproduces the false-pass pattern.

3. **Plan artifact contract** should be extracted as a **declared policy** attached to the native `plan` step in `workflow.pypeline`, not as a separate subworkflow. The existing `ARTIFACT_CONTRACT_POLICY` metadata can be promoted.

4. **Add the missing `test_front_half_native_loop.py`** as an S2a exit gate before proceeding to S2b (gate/revise). The test filename already appears in the exit-gate spec at `master-plan.md:628`.

5. **Resolve the adaptive→static fallback dead letter**: either implement it or remove `"fallback": "static"` from `CRITIQUE_SELECTION_POLICY` (`components.py:944`). The runtime comment at `critique_runtime.py:392-396` says no lens fallback exists — the policy declaration is misleading.
