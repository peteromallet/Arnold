### 5. Recommended Adjustment to the Sprint Plan

**No scope reduction recommended.** The master plan correctly identifies S1a as the hard bar — if any of these artifacts are skipped, the historical false-pass pattern (generated reports accepted as proof) can recur. However:

- **Merge items 11 (replay harness/baseline canonicalizer) into a sub-sprint S1a-2.** The master plan already notes the canonicalizer "is required only if baseline artifacts include content hashes beyond route/state assertions" (line 480). Since the plan explicitly says baselines should start as deterministic route/state assertions (line 209), the canonicalizer is not needed until artifact-hash parity proof is chosen as an escalation. Move it to a conditional gate.

- **Items 12 (headless control-injection) and 13 (installed-package strict loading) can be scoped to smoke proofs in S1a.** The master plan already says S1a needs "smoke proof that the path exists" for installed-package mode (line 451-452), with full gate at S7. Similarly, headless control-injection needs only the API surface existence, not exhaustive scenario coverage. Keep these lightweight.

- **The 8 items that are pure scripts/tests with no dependency on external systems can be built in parallel** by multiple subagents (carrier scan + classification + row registry + reconciliation + structural rejection + negative fixtures + adversarial suite + split-outcome YAML). The only serial dependencies are: `AWF253` must exist before structural rejection tests; the carrier scan must exist before classification; classification must exist before row reconciliation.
