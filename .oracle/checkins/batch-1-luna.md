## North Star

### Four enduring principles

1. **One door per invariant — NOT MET as a complete NBF result.** The candidate does keep NBF writes on the existing `IncidentLedger`/`_IncidentEventJournal`, and `incident/__init__.py` only exports types. However, reservation/terminal/confirmation/producer methods perform their own unlocked read/compare before the common append door, so the single-door transactional invariant is not enforced. Physical admission/dispatch/death doors are explicitly later-batch scope and are correctly unchanged.
2. **Deaths speak — foundation only, not complete evidence.** `WorkerDisposition`, `ObservedProcessDeath`, and `NonWorkerSignalDisposition` provide typed records, signal/killer/cause fields, elapsed time, and distinct ladder IDs. This batch deliberately does not wire signal sites. The schema's permissive OOM and unknown-death handling means even the primitive is not fully truthful.
3. **Models are admitted, not assumed — not implemented in Batch 1 and correctly deferred.** No admission gate, catalog, family, or live-provider caller was changed. This is acceptable only as scope discipline; it is not Batch 1 acceptance evidence for the end-state principle.
4. **Fixes ship on main through the fixer contract — not evidenced yet.** The executor did not commit, push, or merge, as required for the uncommitted Batch 1 handoff. There is no delivery evidence yet that this candidate reaches main; the later delivery batch owns that proof.

### Anti-patterns

- **Single-scan truth — NOT MET.** Confirmation IDs include PID, process start, progress, supervisor incarnation, cause, and a TTL (`disposition.py:32-33`, `schema.py:506-535`), and the simple TTL/separation tests pass. But consumption validates only timestamps and confirmation ID (`disposition.py:70-87`); it does not match second-scan identity/evidence or implement replacement/expiry/restart projections.
- **Anonymous exits — PARTIALLY MET.** The explicit disposition enums and typed `DispatchOutcome.kind=worker_disposition` prevent the old anonymous integer shape in this slice. No real signal branch is wired here, so repository-wide closure is deferred; unknown observations can still carry fabricated killer/signal fields.
- **Judgment-based healthy claims — NOT MET.** Identity fields are present, but no durable equality check for progress, process incarnation, or supervisor/container incarnation is performed on consumption. A schema-shaped confirmation is not positive sustained proof.
- **Identical-fingerprint redispatch without changed precondition — NOT MET.** Sequential same-fingerprint/different-logical-ID contention works, but `reserve` is racy and changed-precondition records are caller-forgeable/unbound. The required durable block cannot be trusted under concurrency.
